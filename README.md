# Word maker (counter)

Приложение для подсчёта очков в игре «Составь слово». Позволяет создать новую игру для подсчета, вводить очки, просматривать результаты, а также сохранять и восстанавливать игры.

## Технологии

- React 19 и React Router 8;
- Mantine 9;
- TypeScript 7;
- Vite 8;
- Vitest и Testing Library.

## Требования

Рекомендуются Node.js 26.13.0 и npm 11.20.0.

## Установка и запуск

```sh
npm ci
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Доступные команды

- `npm run dev` — запускает сервер разработки Vite;
- `npm run build` — проверяет TypeScript и создаёт production-сборку в каталоге `dist`;
- `npm run preview` — локально обслуживает собранную production-версию;
- `npm test` — однократно запускает тесты через Vitest;
- `npm run test:watch` — запускает Vitest в интерактивном режиме.

## Сохранение игр

Сохранения находятся в `localStorage` текущего браузера. Они не синхронизируются между устройствами и удаляются при очистке данных сайта.
