# Планируемые улучшения

Файл содержит результаты аудита кода из пункта 2 общего плана. Статус обновлён 2026-10-31: перечисленные проблемы исправлены и покрыты тестами.

## Высокий приоритет

- [x] **Реализовать восстановление игры.** Сейчас `src/pages/RestoreGame/RestoreGame.tsx` только отображает имена сохранений. Необходимо загружать данные из `localStorage`, восстанавливать контекст и переходить к игре.
- [x] **Предотвратить падение страницы результатов без активной игры.** При прямом переходе на `/result` или после перезагрузки `src/pages/Result/helpers/getWinners.ts` обращается к несуществующему игроку, а `src/pages/Result/Result.tsx` ожидает обязательного первого и второго победителя.
- [x] **Исправить определение мест при ничьей.** В `src/pages/Result/helpers/getWinners.ts` игроки находятся по значению очков через `findIndex`. При одинаковых результатах один игрок может занять несколько мест.

## Средний приоритет

- [x] **Исправить обработку нулевых очков.** `src/pages/ActiveGame/ActiveGame.tsx` не позволяет добавить `0`, а `src/pages/Result/helpers/getPointsMatrix.ts` отображает сохранённый ноль как `--`.
- [x] **Определить поведение при перезагрузке и прямых переходах.** Состояние в `src/contexts/ActiveGameContext.tsx` хранится только в памяти, а маршруты `/game`, `/save` и `/result` не проверяют наличие активной игры.
- [x] **Добавить валидацию сохранений.** В `src/pages/SaveGame/SaveGame.tsx` необходимо проверять наличие активной игры и непустое имя, обрабатывать совпадения имён и ошибки `localStorage`, а также исключить молчаливую перезапись существующего сохранения.
- [x] **Запретить игроков с пустыми именами.** В `src/pages/NewGame/hooks/useNewGame.ts` проверка выполняется до `trim()`, поэтому строка из пробелов превращается в пустое имя и учитывается в количестве игроков.

## Низкий приоритет

- [x] **Исправить фильтрацию ключей сохранений.** В `src/pages/RestoreGame/helpers/getSavedGames.ts` следует распознавать только ключи с префиксом `WORD_MAKER_`.
- [x] **Добавить явный маршрут для неизвестных адресов.** В `src/routing/Routing.tsx` отсутствует `path="*"`, поэтому отображение пользовательской `Error404` для любого неизвестного адреса не гарантировано.
- [x] **Убрать небезопасную заглушку контекста.** В `src/contexts/ActiveGameContext.tsx` используется `{} as ActiveGameContextValue`, что скрывает ошибку обращения к контексту вне провайдера.
- [x] **Исправить язык документа.** В `public/index.html` указано `lang="en"` при русскоязычном интерфейсе.
